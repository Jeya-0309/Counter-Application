# Counter Application

A simple Counter Application built using React.js.

## Live Demo

[View Counter Application](https://counterapplication-one.vercel.app/)

## Features

- Increment the counter by 1.
- Decrement the counter by 1.
- Reset the counter to 0.
- Prevents negative values.
- Displays a message when the minimum limit is reached.

## Technologies Used

- React.js
- JavaScript
- CSS
- useState Hook


## Learning Objective

Practised React `useState`, event handling, state management, and conditional rendering.
